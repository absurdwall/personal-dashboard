# 完整使用手册

Personal Dashboard **1.0.0 Beta 1**，build **5.0.4**，面向 Apple Silicon Mac。[安装与首用](installation.html) · [隐私与资料](privacy.html) · [已知限制](limitations.html) · [发行说明](release-notes.html)

## 认识 Personal Dashboard

Personal Dashboard 把任务、每日安排、日历、习惯和 AI 协作放在一个 Mac 应用中。你可以先使用本地功能，再决定是否连接 Codex。无需 Dashboard 账号、Obsidian、滴答或开发工具。AI 使用你自己的 ChatGPT 登录和可用额度，网络和账户条件另计。

首次 Beta 为 **1.0.0 Beta 1**，首轮面向 Apple Silicon Mac。它采用本地签名，尚未经过 Apple 公证。Intel、Windows 和移动端不在本轮支持范围。下载前请核对发行说明中的具体包、系统验证范围及已知限制；最低系统配置不代表在那个系统上完成了测试。

## 安装与首次打开

1. 从版本明确的发行入口下载 DMG，同时取得该文件的 SHA-256；按发行说明核对文件名、版本和校验和。
2. 打开 DMG，把 **Personal Dashboard** 拖入 **Applications / 应用程序**。
3. 等待复制完成，推出 DMG，再从“应用程序”启动复制品。
4. 如果 macOS 阻止打开，先尝试启动一次，再按“系统设置 → 隐私与安全性”中针对该 App 的提示选择“仍要打开”，并完成系统要求的确认。界面名称可能随 macOS 版本变化。[Apple 的说明](https://support.apple.com/zh-cn/102445)提供了对应流程。

不要关闭全局 Gatekeeper。若设备由公司或学校管理，请联系设备管理员；如果提示文件损坏、签名异常或没有放行选项，先停止重复尝试，重新核对下载和校验和，并按下文反馈。系统放行只解决启动限制，不证明应用已通过安全审核。

## 创建自己的个人空间

在 Today 的空白状态或 **设置 → 数据与 Vault** 点击 **“新建个人空间…”**。在系统面板中选择可写位置，为一个新文件夹命名，再保存。应用会创建空白的必要目录并选择它；不会导入演示资料或维护者的记录。以后界面中的“Vault”就是这个由你选择的个人资料文件夹。

已有兼容资料时，可选 **“选择已有兼容 Vault…”**。兼容目录需要 `.obsidian` 格式标记和 `life/Journal/Daily`；无需安装 Obsidian。普通文件夹不会被静默转换。若选择不兼容或创建失败，阅读提示，换一个新文件夹名称或选择正确目录；之前的选择保留。不要通过复制别人的个人 Vault 来开始使用。

## 先完成三个小操作

- **任务**：点击“新建任务”，输入“买水果”，添加到“收集箱”。可以先不设日期。
- **习惯**：点击“添加习惯”，填写“散步”，选择“每日完成”，核对开始日期，再点“保存习惯”。用该习惯的完成控件记录一次本地完成。
- **今天**：打开当天的“当日 · 时间轴”，在“写一句”输入“今天开始试用”，点“保存记录”。日期尚无 Daily Record 时，这个明确保存动作会创建最小日记录。

检查保存提示，再退出应用并重新打开，确认三个结果仍在。只浏览日期不会自动创建日记；创建 Task 或 Habit 也不要求先有当天日记。

## 任务、Today 与 Calendar

“任务”“今天”和“日历”共享同一条 Task。改名、安排日期或完成后，其他页面读取的是同一身份，不需要各建一份。收集箱是默认清单；“今日”是按日期汇总的视图。

任务可有名称、可选内容、日期及时刻，也可保持无日期。详情中可维护清单、父子关系、优先级与标签；清单文件夹用于分组。父任务与子任务各自保留日期和完成状态。计划执行区间表示打算何时做，并非实际耗时；跨午夜的结束日期应填真实的下一日期。

需要取消定时而保留日期时，使用“清除时刻与执行区间”；清除全部安排用“清除日期与时刻”。逾期不会自动完成、失败或改到今天。可以完成、重开、放弃或删除任务；删除后可在“已删除”中恢复。“放弃”和“完成”分开保留。归档清单保留历史，不会替你完成或放弃其任务。

Calendar 先展示月份，选择日期可查看记录并在该日创建任务。浏览未来日期可以安排任务，但不能把未来的活动记作已发生事实。

## 日记录、计划与复盘

Today 的早间、当日和晚间内容属于同一日期的 Daily Record。当前安排可以修订；初始早间基准和修订历史用于保留当时的安排及变化。时间经过不代表事情发生，计划和已确认事实有各自标记。无明确时刻的内容保留在未定时间区。

一句记录可选“日常记录”或“健身”；健身短句提供背景，不会自动完成习惯或写回滴答。更正会保留修改痕迹。若想生成或重排计划，可在 Collaboration 清楚说明目标日期和想保存的改变。点击“开始复盘今天”会准备可编辑的协作草稿；检查后自行发送。没有复盘不会产生必须补写的欠账。

应用的生活日从本地 **04:00 到次日 04:00 前**。例如周六凌晨 02:00 仍属于周五的生活日；事件的真实时间戳不被改写。跨午夜时，核对当前选中日期和会话目标日期。

## 习惯与统计

Habits 可管理本地习惯、名称、开始日期、分组及目标，也可暂时停用后恢复。目标包括每日完成、每周达标天数及每日时间阈值。每周目标按周一至周日的不同达标日计算：同一天多次完成只算一天。

修改既有目标后，界面会显示待生效日期；每日目标从下一生活日、每周目标从下一周切换，不追改过去或当前周期的达标解释。按“查看详情”检查日期、目标和证据来源。

本地完成和已有外部证据分别保留；同一习惯同一天合并计一次。撤回本地完成后，如果外部来源仍确认完成，合并结果仍可能勾选。时间阈值打卡只声明达标，不证明活动实际发生时刻。未知或未覆盖的日期不会自动算失败；“至少”和“已知”统计不能当作完整历史。

首次使用无需滴答或外部快照。本轮不提供新用户的滴答接入向导，也不会自动导入所有外部任务和习惯。

## 连接 Codex 与使用 Collaboration

先按 [Codex 安装与连接说明](installation.html#codex)安装已核对的外部 Codex。DMG 不附带、下载或代装 Codex。然后进入 **设置 → Codex**，点 **“检查连接”**，按提示点 **“连接 ChatGPT”**，使用自己的账号完成浏览器登录，再回到应用检查连接。Dashboard 保存自己的独立连接资料；终端或其他客户端已登录不等于 Dashboard 已登录。

只有当前连接提供的模型和推理强度可用。实验协议、账户条件及额度可能影响能力；运行时兼容检查通过不保证所有模型、账号或语音服务可用。查看对应发行的验证记录。

在 **协作** 中输入消息，核对目标日期，再手动“发送”；发送也可创建新对话。可以请求讨论方案，也可以明确交代保存。例如：“请在今天添加一个本地任务：买水果。” 请求先看方案时，先审阅；明确的保存指令可对对应来源执行。模型回复、会话已保存和实际任务/日记/习惯保存是不同结果：查看操作结果，并返回相应页面刷新核对。遇到结果待确认时，先检查实际来源再重试，避免重复执行。

工作历史记录过程与失败后的恢复；它不取代个人资料正本。长期背景和衔接信息也不是当前任务状态。新空间缺少可选的长期背景或流程参考时，不必复制维护者的配置。AI 需要在线服务；发送前考虑消息和所读资料会交给已连接的服务处理。避免在反馈中公开会话、账号或凭证。

## 听写

在协作草稿旁点 **“开始听写”**，按系统提示允许麦克风，等到“正在录音，可以说话”后再说话。点 **“停止听写”**，等待整理完成，检查并修改草稿，再自行“发送”。听写不会自动提交消息。

音频通过 Codex 在线处理，不是离线识别或实时语音对话。服务、账户额度及网络可能导致失败或文字不完整；未确认预览可能与最终文字重叠，发送前请检查并删去重复内容。点“取消”会丢弃本次听写输入，开始听写前的草稿保留。离开协作、切换会话或目标日期会停止捕获，将已收到的文字整理到原会话和日期的草稿。若保存失败，先保留或复制重要文字，不要把尚未保存的屏幕内容当作已持久保存。

## 自动早间安排

**设置 → Codex → 自动早间计划** 默认关闭。想启用时，选择本地触发时间，勾选启用，再保存。没有旧日程时无需交接。只有已经使用其他自动早间日程时，才勾选“我已有其他自动早间安排日程”，在 App 之外检查或暂停旧日程后确认交接；Dashboard 不会替你查找、停用外部日程。

App 进程运行且条件可用时，才会在到时后检查并尝试创建当天缺少的计划初稿。当天稍后打开 App 会再检查；已有有效安排受到保护。关闭窗口通常只是隐藏；真正“退出”后不会运行。睡眠、断网、未登录、额度或读取失败会影响执行；不会唤醒 Mac，也不保证设定时刻必达。用“查看自动运行”和 Daily Record 核对结果。自动运行不应被解释为自动完成 Tasks、记录已发生事实或同步外部资料。

## 离线使用、资料位置与同步

本地 Task、Habit 和日记录读写不依赖 AI。断网、没有 Codex 或尚未登录时，仍可使用这些功能，前提是你选择的资料文件在这台 Mac 上可用。在线 AI、听写和外部来源需要相应连接。

个人空间中的 `life/Journal/Daily/` 保存日记录；隐藏的 `life/.personal-dashboard/` 保存任务、习惯定义、本地完成与相关资料。不要只复制可见日记而遗漏隐藏目录。设置、会话历史、草稿、自动安排偏好及独立 Codex 连接资料位于这台 Mac 的应用资料目录 `~/Library/Application Support/com.tortillaflat.personal-dashboard/`；连接资料可能包含敏感登录信息。

若使用 Google Drive，先由其桌面客户端让整个个人空间保持本地可用，再在 Dashboard 选择它。Dashboard 不管理 Google 登录、上传或云端冲突；“本地已保存”不代表“云端已同步”。先确认上一台电脑同步完成，再在另一台编辑，避免同时改同一份文件。本轮不承诺跨设备实时同步应用设置和聊天。

## 备份、恢复与编辑冲突

定期退出 Dashboard，关闭正在编辑这些文件的其他程序，把整个个人空间复制到独立备份位置，包含隐藏目录。若要保留本机聊天、草稿和设置，也单独备份上述应用资料目录；把含登录资料的备份当作敏感资料保管，切勿上传到反馈 Issue。应用没有面向本轮新资料的“一键整库恢复”承诺，历史 Exercise/Profile 的备份功能不等于当前个人空间备份。

恢复时先保留当前文件的副本，退出应用和外部编辑器，把选定备份复制到一个新的恢复文件夹，再通过“选择已有兼容 Vault…”打开它。核对日记录、任务和习惯，并退出重开确认。要恢复本机应用资料，先保留当前目录，再在应用退出时按备份替换；若移动路径变化，重新选择个人空间，必要时重新连接 ChatGPT。不要在 App 运行时覆盖资料，也不要假定旧程序能读取新版本保存的数据。

如果提示文件已变化或保存结果未确认，保留草稿、检查原文件，再刷新并重新核对。应用为受保护的替换保存保留恢复材料于 `life/.personal-dashboard/recovery/today/`，但不会自动合并、回放或选择“正确版本”。它不是完整备份；恢复项可能继续反映外部编辑。关闭所有相关编辑器后比较内容，只在理解差异后手动恢复，必要时先求助。不要批量删除恢复材料来消除错误提示。

## 升级、卸载与反馈

升级前备份，退出旧 App，按新版本安装说明替换“应用程序”里的同名 App。保持原应用身份和个人空间；不要另建个人空间来“迁移”。启动后核对资料及版本，并保留原备份。内部 4.0.7 与公开 1.0.0 系列的显示/构建映射以该发行记录为准；这不是任意降级承诺。

卸载先退出 App，再把 `/Applications/Personal Dashboard.app` 移到废纸篓。你选择的个人空间和本机应用资料仍保留；需要永久删除时先备份并分别确认，不要把卸载 App 误当作清除了聊天或账号资料。外部 Codex 是独立安装，也单独保留。

反馈到本仓库的 GitHub Issues 时，提供版本/build、macOS 和芯片、复现步骤、预期/实际结果，以及是否本地功能或 AI/听写问题。截图优先用合成资料；遮去姓名、目录、任务/聊天正文、邮箱及任何 token。先保留原始证据在自己电脑，不直接公开整份个人空间、应用资料或 auth 文件。发行验收记录会区分通过、失败及未执行；全新 macOS 用户和另一自有账户测试已延后，不能当作通过。
