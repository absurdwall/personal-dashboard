安装与首次使用

产品介绍 · 完整手册 · 已知限制 · 发行说明

安装 1.0.0 Beta 1，build 5.0.4：Apple Silicon DMG · SHA256SUMS。

先确认条件

  • 首轮仅 Apple Silicon（M 系列）Mac；Intel、Windows 和移动端不在本轮交付范围。
  • 实际验证环境为 macOS 27.0.1。包内最低系统元数据为 12.0，但尚未验证较低系统，不能据此承诺兼容 macOS 12。
  • 本地任务、习惯和日记录无需 Codex、ChatGPT 登录、Obsidian、滴答、Node 或 Rust。
  • AI、听写与自动早间安排需要另行安装兼容的外部 Codex、自己的可用 ChatGPT 账号及网络；额度与服务条件会影响结果。

安装 DMG

  1. 在明确的 v1.0.0-beta.1 发行中取得 Personal-Dashboard_1.0.0-beta.1_arm64.dmg 与 SHA256SUMS；不要使用 latest 代替指定 Beta。
  2. 在下载目录中执行 shasum -a 256 Personal-Dashboard_1.0.0-beta.1_arm64.dmg，将结果与同一发行的 SHA256SUMS 核对。校验和验证字节一致性，不证明开发者身份或安全性。
  3. 打开 DMG，把 Personal Dashboard 拖到 Applications / 应用程序，等待复制完成。
  4. 推出 DMG，再从“应用程序”打开 App。不要一直运行挂载盘里的副本。

本轮采用本地 ad-hoc 签名，未使用 Apple 验证的 Developer ID，未公证。首次启动可能被 macOS 拦截。如果你确认来源可信且文件未被篡改，先尝试打开一次，再进入 系统设置 → 隐私与安全性 → 仍要打开，按系统提示确认。具体选项随系统版本变化，参阅 Apple 官方说明。

受管理设备可能禁止例外，请联系设备管理员。遇到损坏、恶意软件、签名异常或没有允许选项时，保留完整提示，核对下载和版本并反馈；不要关闭全局 Gatekeeper 或反复绕过警告。真实公开下载的 quarantine/Finder 复制/推出/单 App 放行链已在已有 macOS 用户上执行；起初被阻止后，用户完成“仍要打开”和密码确认。这不是全新用户验收，见限制。

创建个人空间

在 Today 空白页或 设置 → 数据与 Vault 选择 新建个人空间…，选择可写位置，为新文件夹命名，再保存。只创建必要目录，不带演示记录、个人背景、技能或账号。文件夹里 .obsidian 是兼容格式标记，使用 Dashboard 无需安装 Obsidian。

已有资料时，选择 选择已有兼容 Vault…；目录需要 .obsidian 与 life/Journal/Daily。普通非空文件夹不会被自动转换。取消或失败会保留原选择，按提示换新名称/位置即可。

做三个小操作

  1. 在“任务”新建“买水果”，加入收集箱。日期可留空；想在 Today/Calendar 看它，可安排到今天。
  2. 在“习惯”添加“散步”，选每日完成并保存，完成一次后再撤回，核对勾选结果。
  3. 在“今天”的“写一句”保存“今天开始试用”。明确保存才建立首条最小 Daily Record；浏览日期不会造记录。
  4. 使用菜单退出 App，再重新打开并逐项核对。关闭窗口可能只是隐藏，不能代替真正退出。

安装 Codex 并连接自己的 ChatGPT

需要 AI 时，自行在 Terminal 执行已核对的官方独立安装路径：

curl -fsSL https://chatgpt.com/codex/install.sh | sh -s -- --release 0.160.0
"$HOME/.local/bin/codex" --version

预期版本输出为 codex-cli 0.160.0。独立安装默认位于 ~/.local/bin，Dashboard 从 Finder 启动也会查找这里，因此核对版本不依赖 Terminal 的 PATH。保持完整安装结构，不要只复制其中一个可执行文件。安装脚本及发行可用性可能变化；如果固定版本无法取得，先查看已知限制并反馈。

进入 设置 → Codex → 检查连接 → 连接 ChatGPT，在浏览器中登录自己的账号，回到 App 再检查。Dashboard 使用独立连接资料；其他 Codex/ChatGPT 客户端已经登录，不代表 Dashboard 已登录。不要复制其他客户端的凭证文件。仅使用当前连接列出的模型和推理强度。

先请求一个合成修改，例如“请为今天添加本地任务：阅读一页”。检查独立操作结果，再到任务页面和资料中读回。回复、会话保存和业务保存是三个不同结果；结果不确定时先核对，避免重复创建。

Dashboard 不内附、自动下载或代装 Codex。安装任意 ChatGPT/Codex App 不等于安装了这里检查过的 CLI；运行时还需要通过 Dashboard 的协议与启动检查。独立安装、schema 与启动握手已本地核实；新账号登录、真实模型写入及中英麦克风质量仍未完成本轮验收，不保证所有账号可用。

来源：OpenAI 官方 Codex CLI 文档。固定 --release 参数已在本轮隔离安装中实际核对，详见工程运行时记录。继续阅读协作与听写手册。

Install and start

Product · Complete manual · Known limitations · Release notes

Install 1.0.0 Beta 1, build 5.0.4: Apple Silicon DMG · SHA256SUMS.

Check the requirements

  • This beta targets Apple Silicon (M-series) Macs. Intel, Windows and mobile packages are outside this release.
  • The actual test host is macOS 27.0.1. The package declares a 12.0 minimum, but lower systems have not been validated; this is not a macOS 12 compatibility promise.
  • Local Tasks, Habits and Daily Records need no Codex, ChatGPT sign-in, Obsidian, Dida, Node or Rust.
  • AI, dictation and automatic morning planning require a separately installed compatible Codex, your own eligible ChatGPT account and network access. Account limits and service conditions apply.

Install the DMG

  1. Obtain Personal-Dashboard_1.0.0-beta.1_arm64.dmg and SHA256SUMS from the exact v1.0.0-beta.1 release. Do not substitute a latest link for this prerelease.
  2. In the download folder, run shasum -a 256 Personal-Dashboard_1.0.0-beta.1_arm64.dmg and compare with that release's SHA256SUMS. A checksum verifies matching bytes, not developer identity or safety.
  3. Open the DMG, drag Personal Dashboard into Applications, and wait for copying to finish.
  4. Eject the DMG, then open the copy in Applications. Do not keep running the mounted copy.

This beta is locally ad-hoc signed. It has no verified Developer ID and is not notarized. If macOS blocks it and you trust its source and intact bytes, first try opening it, then follow System Settings → Privacy & Security → Open Anyway and the system confirmation. Follow Apple's current instructions for the options on your system.

Managed devices may prohibit an exception; contact the administrator. For damaged-app, malware or signature warnings, or a missing override, retain the exact warning, check the download/version and report it. Keep Gatekeeper enabled. The actual public-download quarantine/Finder/eject/per-App opening chain was checked on the existing macOS user; after the initial block, the user completed Open Anyway/password confirmation. This is not clean-user acceptance; see limitations.

Create your personal space

From empty Today or Settings → Data & Vault, choose Create personal space…, select a writable location and name a new folder, then save. Only necessary directories are created, with no sample records, personal background, skills or accounts. The .obsidian directory is a format marker; the Obsidian app is not required.

For existing data, choose Choose existing compatible Vault…. It needs .obsidian and life/Journal/Daily. Ordinary nonempty folders are not silently converted. Cancellation or failure retains the previous selection; follow the message to choose another name or location.

Try three small actions

  1. In Tasks, create “Buy fruit” in Inbox. A date is optional; assign today to see the same Task in Today and Calendar.
  2. In Habits, add “Walk”, choose daily completion, save, complete once and withdraw it to check the result.
  3. In Today, save “Started trying Dashboard” as a short note. Only an explicit save creates the first minimal Daily Record; browsing dates does not create records.
  4. Quit through the app menu, reopen and check all three. Closing the window may only hide it.

Install Codex and connect your ChatGPT

For optional AI, install the checked official standalone CLI yourself in Terminal:

curl -fsSL https://chatgpt.com/codex/install.sh | sh -s -- --release 0.160.0
"$HOME/.local/bin/codex" --version

The expected version is codex-cli 0.160.0. The default standalone installation is in ~/.local/bin; Dashboard also searches there when launched from Finder. The explicit version-check path does not depend on Terminal PATH. Keep the complete installation together rather than copying out one executable. The installer and release availability may change; consult limitations and report an unavailable pinned release.

Open Settings → Codex → Check connection → Connect ChatGPT. Sign in with your own account in the browser, return and check again. Dashboard keeps independent connection data; another Codex or ChatGPT client being signed in does not sign Dashboard in. Do not copy another client's credentials. Use only models and reasoning efforts offered by the current connection.

Start with a synthetic change, such as “Add a local Task for today: Read one page.” Check the individual action result, then independently reread the Task page and saved source. A reply, a saved conversation and a saved business change are separate results. Check uncertain outcomes before retrying to avoid duplicates.

Dashboard does not bundle, download or install Codex. Installing an arbitrary ChatGPT/Codex app is not the same as this checked standalone CLI; Dashboard also checks protocol and startup compatibility. The independent install, schema and initialization handshake were checked locally. Fresh-account login, real model writes and multilingual microphone quality have not passed this run's acceptance; not every account is guaranteed to work.

Source: official OpenAI Codex CLI documentation. The pinned --release argument was actually checked in an isolated install; see the engineering runtime record. Continue with Collaboration and dictation in the manual.
