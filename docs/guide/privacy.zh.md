# 隐私与资料

[产品介绍](../index.html) · [安装指南](installation.html) · [完整手册](manual.html) · [限制](limitations.html)

## 本地资料由你保管

个人空间是你选择的文件夹，保存任务、习惯与 Daily Records。App 的设置、会话、草稿与独立 Codex 连接资料另存在本机应用资料目录。具体路径和备份步骤见[完整手册](manual.html)。本轮不提供 Dashboard 云账号或由 App 管理的整库同步。

新建个人空间不会复制维护者的资料、个人技能、登录或演示记录。本地功能不要求 AI 或外部账号。卸载 App 会保留个人空间和本机应用资料；如需删除，先备份并明确识别目录。

## 启用在线 AI 前

发送 Collaboration 消息时，消息、会话上下文与为完成请求所读取的相关 Tasks、日记录、Habit 资料及个人空间文档，可能被交给所连接的 AI 服务处理。可选长期背景和衔接笔记也可作为上下文。检查目标日期与请求内容，只发送你愿意交给该服务的资料。

听写会使用麦克风，并通过 Codex 在线处理音频及转写。文字先落为可编辑草稿，由你发送；“取消”丢弃本次听写输入。停止、导航和退出边界见[手册](manual.html)。这不是离线识别或实时语音聊天。

Dashboard 使用独立 Codex 连接资料，登录自己的 ChatGPT。不要复制他人的凭证；连接文件和备份可能包含敏感认证资料。这里不承诺本地会话、文件或凭证由 Dashboard 加密。在线服务的处理与账户限制也取决于其当前条款和设置。

## 可选服务与同步

已有可选滴答连接的操作保留独立来源与结果；没有配置时无需开户。本轮不建设新用户滴答接入，也不会把本地修改自动当成外部保存成功。

使用云盘时，上传和同步由你选择的桌面客户端负责。“本地已保存”不代表云端已完成；应用设置、聊天和凭证也不承诺随个人空间同步。请保护所选云盘和备份的访问权限。

## 网站与反馈

此静态页面没有加入分析、广告、外部字体、跟踪脚本或表单服务。语言偏好只保存在当前浏览器的本地存储中；不需要登录。打开 GitHub 或官方帮助链接时会离开本页，适用相应服务的规则。静态网页由 GitHub Pages 托管，应用下载使用 GitHub Releases；这些服务自行处理其请求日志。

提交 [GitHub 反馈](https://github.com/absurdwall/personal-dashboard/issues)时，使用合成复现，遮去账号、邮箱、姓名、私人路径、正文与 token。不要上传整个个人空间、应用资料目录、凭证或未脱敏的系统日志。截图中的系统菜单也可能暴露其他历史内容，请只截取所需 App 区域。
