1.0.0 Beta 1 发行说明

产品介绍 · 安装与首用 · 完整手册 · 隐私 · 限制

当前状态

尚未公开发布，下载未开放。 当前内容供具体候选评审；只有维护者确认后才会启用网页、发行 tag 与 Release 资产。未完成实际发布前，规格和最终发行票保持未关闭。

发行显示名为 1.0.0 Beta 1，数值版本 1.0.0，当前声明 build 5.0.3，计划 tag 为 v1.0.0-beta.1。只有 Apple Silicon / arm64 的 Personal-Dashboard_1.0.0-beta.1_arm64.dmg，配套 SHA256SUMS。应用身份保持 com.tortillaflat.personal-dashboard，不因公开版本重新建立个人资料。

本轮准备

  • 空白个人空间创建与已有兼容 Vault 选择；任务、习惯与最小日记录独立保存。
  • Tasks、Today、Calendar 共享 Task；生活日按 04:00 边界归属。
  • 外部独立 Codex 兼容发现，App 内自己的 ChatGPT 连接；听写为在线可编辑草稿，自动安排默认关闭且仅在 App 运行期间检查。
  • Apple Silicon DMG、拖入 Applications、明确版本与 SHA-256、本地签名/未公证声明。
  • 双语网页、安装指南、完整手册、隐私说明与真实合成截图；保留现有可选集成。

候选对应关系

初始审核包 build 5.0.1 来自源码 72a96980c081e5fb23010e6ef5ff128a16ed9185；本页截图取自该候选的隔离合成资料。它不是最终公开资产。现已声明修复后的最终候选 build 5.0.3，等待独立复核后的源码绑定构建与验收，不会重标或覆盖旧候选字节。build 5.0.2 来自源码 7eac9b7eb7c475616115889f7e84f4cd2862fd58，静态包检查通过后，原生 QA 发现空白 Habits 页头副标题仍需修正；真实记录单独保留。

最终准备

最终源码修复本地 Habit 固定说明、首个习惯指引与重启后的短记录类别翻译，不翻译用户正文。打包准备支持全新外部缓存，并补充 Rust 标准库及运行时许可证。源码修复不等于最终包验收；实际结果和未执行项以最终验收记录为准。

支持范围与未运行验收

实际测试主机为 Apple Silicon macOS 27.0.1；包内最低元数据为 macOS 12.0，较低系统尚未验证。本轮没有 Intel、Windows 或移动包，没有自动更新，也未 Apple 公证。

真实模型、麦克风质量、全新 macOS 用户、独立账号及最终公开下载链的状态分别列在已知限制。历史通过、协议握手或自动测试不能补齐这些空白。内部 4.0.7 到公开 1.0.0 的数值显示重新起始，当前声明 build 从旧版递增为 5.0.3，应用身份及资料位置保留；实际替换安装的数据保留应核对相应候选验收，不保证任意降级。

1.0.0 Beta 1 release notes

Current status

Not publicly released. Downloads are closed. This content is for a concrete candidate review. Website hosting, the release tag and downloadable assets require the maintainer's confirmation. The parent specification and final release ticket stay open until actual publication.

The release display is 1.0.0 Beta 1, numeric version 1.0.0, current declared build 5.0.3, and intended tag v1.0.0-beta.1. The Apple Silicon / arm64 asset is Personal-Dashboard_1.0.0-beta.1_arm64.dmg with SHA256SUMS. Application identity remains com.tortillaflat.personal-dashboard; public numbering does not create another personal-data identity.

Prepared in this round

  • Empty personal-space creation and existing compatible Vault selection; independent local Tasks, Habits and minimal Daily Records.
  • One Task identity across Tasks, Today and Calendar; a 04:00 lived-day boundary.
  • Compatible external standalone Codex discovery and your own in-app ChatGPT connection. Dictation becomes an online editable draft. Automation defaults off and checks only while the app runs.
  • Apple Silicon DMG with an Applications drag target, explicit version and SHA-256, local-signature and no-notarization disclosure.
  • Bilingual website, installation guide, complete manual, privacy notes and real synthetic screenshots; existing optional integrations retained.

Historical success, a protocol handshake or automated tests do not fill those gaps. Public numeric numbering restarts at 1.0.0 after internal 4.0.7, while the current declared build advances to 5.0.3 and identity/data locations remain stable.
