已知限制与验证范围

产品介绍 · 安装指南 · 完整手册 · 发行说明

这是首次受邀 Beta，请先阅读以下限制。小范围邀请不构成访问控制；公开网页、源码和下载也可被其他人访问。

已完成的本轮检查

已在 Apple Silicon、macOS 27.0.1 上用隔离合成资料检查：本地业务保存与读回、原有版本的真正退出重开、Task/Habit/最小日记录持久化、偏好保留；新候选的空白个人空间创建与本地首用；独立 Codex 0.160.0 被发现且保持未登录；自动安排默认关闭，无旧日程时可以主动启用，未登录失败如实显示。另有自动化的冲突、草稿、去重、运行时兼容、版本与静态包检查。

候选包的签名、架构、DMG 内容及校验记录见打包证据。这些检查不代替未运行的真实用户或服务验收。

build 5.0.4 源码 eb49860e634bb5af4c25a21bd901ed9613abf84a 的十项静态包检查与一次实际 Settings 桌面/窄窗视觉确认通过。完整同用户业务/重启/升级/恢复基线仍绑定 5.0.3，没有重标为在 5.0.4 重跑。

公开版本的 DMG 与校验和经匿名 HTTP 200 下载，实际字节与已批准哈希一致。未登录浏览器下载带有真实 quarantine；Finder 复制匹配的 App、推出 DMG 后，macOS 起初阻止了未公证的 App。用户亲自完成单 App“仍要打开”和密码确认，精确复制的程序显示原生窗口并正常退出；没有移除 quarantine 或修改全局 Gatekeeper。这使用已有 macOS 用户；Gatekeeper 重启未保留请求的隔离覆盖，实际打开已有资料，未请求业务修改或模型调用，不算全新用户/另一机器验收。正式本机 4.0.7 安装另已备份并更新为精确 5.0.4，选定 Vault 设置保持不变。实际发布记录。

尚未完成

  • 全新 macOS 用户/另一测试机安装、独立 ChatGPT 账号登录：本轮经维护者同意暂缓，仍是未执行。
  • 本轮真实模型修改后独立读回、真实中文/英文/中英混合麦克风质量、真实 AI 自动早间安排完整闭环。
  • 物理断网测试未执行。未登录时的本地保存是另一类证据。未执行真正缺少运行时的原生测试，因为机器仍有已安装的 ChatGPT 回退运行时；空 PATH 不代表它不存在。
  • 低于已测 macOS 27.0.1 的系统；包内 12.0 最低元数据不等于已验证支持。

候选与图片身份

当前三张图片来自真实 build 5.0.3 原生窗口和隔离合成资料。build 5.0.3 已从精确源码 e8ddeb8aab2d6d7bfc74d805839b633c9065af45 构建，十项静态包检查通过，其原生记录覆盖首用、重启、隔离升级与恢复。当前声明 5.0.4 仅修正 Settings 视觉尺寸，十项静态包检查与一次 Settings 桌面/窄窗视觉确认通过；此次视觉小修没有重跑完整原生业务/升级/恢复，真实 5.0.3 基线分别保留。实际源码、可执行文件和图片哈希已按来源记录核对，初始 5.0.1 图片身份另按历史保留，没有静默重标。本地 Habit 无需外部快照。最终验收记录将真实包及原生结果与这些历史图片分别列明。

使用边界

  • 首轮只准备 Apple Silicon Mac；没有 Intel、Universal、Windows 或移动发行。
  • 本地签名、未公证；没有自动更新系统。
  • Codex 外部安装，账号、模型、额度和在线服务可用性有条件；不保证所有 ChatGPT 账号或任意 Codex 版本可用。
  • 听写是在线草稿输入；显式取消丢弃本次输入，不是实时语音对话。
  • 自动安排仅 App 进程运行时检查；睡眠、退出或失败可能导致不运行，不自动唤醒，不保证到时必达。
  • 不提供新用户滴答接入或 App 管理的云同步；本地、外部和云盘结果各自核对。
  • 恢复材料不是完整备份；冲突不会自动合并，任意降级不保证格式兼容。

反馈请按隐私与资料脱敏，附具体版本/build、macOS、芯片及复现步骤。

Known limitations and validation

Product · Installation · Complete manual · Release notes

This is an invited beta with the limitations below. An invitation is not access control: public pages, source and downloads are accessible to others.

Checked in this run

On Apple Silicon macOS 27.0.1, isolated synthetic checks covered local business saves/readback, actual quit/relaunch of the previous version, persistent Tasks/Habits/minimal Daily Records and preferences; the new candidate's empty-space creation and local first use; discovery of standalone Codex 0.160.0 with an independent signed-out profile; automation off by default, enabling without a nonexistent old schedule, and a visible signed-out failure. Automated coverage also checks conflicts, drafts, deduplication, runtime compatibility, versioning and package structure.

See the packaging evidence for signature, architecture, DMG contents and hashes. These checks do not stand in for unperformed real-user or service acceptance.

Build 5.0.4 source eb49860e634bb5af4c25a21bd901ed9613abf84a passed all ten static package checks and one actual Settings desktop/narrow visual round. The full same-user business/restart/upgrade/recovery baseline remains build 5.0.3; it was not relabeled as repeated on 5.0.4.

The public versioned DMG and checksum returned anonymous HTTP 200 and matched the approved bytes. A signed-out browser download carried real quarantine; Finder copied the matching App, the DMG was ejected, and macOS initially blocked this unnotarized App. The user completed per-App Open Anyway and password confirmation; the exact copy displayed a native window and normally quit. No quarantine removal or global Gatekeeper change was used. This was the existing macOS user and existing profile after Gatekeeper relaunched without the requested isolation overrides; no business edits/model calls were requested. It is not clean-user/another-machine acceptance. The formal local 4.0.7 installation was separately backed up and updated to exact 5.0.4, with selected-Vault settings unchanged. Actual publication receipt.

Not yet performed

  • Clean macOS-user/other-machine installation and independent ChatGPT-account login: deferred with the maintainer's agreement in this run; not passed.
  • Real model changes with independent readback, real Chinese/English/mixed microphone quality, and the complete live-AI automatic morning-plan flow in this run.
  • Physical network-disconnection testing has not been run. Signed-out local saves are separate evidence. A genuinely absent-runtime native test was not run because an installed ChatGPT fallback remained available; empty PATH does not prove its absence.
  • Systems below tested macOS 27.0.1. The 12.0 package minimum metadata is not validated support.

Candidate and image identity

Current images are three real native captures of build 5.0.3 with isolated synthetic data. Build 5.0.3 was built from exact source e8ddeb8aab2d6d7bfc74d805839b633c9065af45 and passed all ten static package checks. Its native receipt records first use, restart, isolated upgrade and recovery. Current declaration 5.0.4 is a Settings-only visual correction; its ten static package checks and one desktop/narrow Settings visual confirmation passed. Full native business/upgrade/recovery suites were not repeated for this visual-only delta; their actual 5.0.3 baseline remains separate. Their actual source/executable/image hashes were verified against provenance; historical 5.0.1 image identity remains separately recorded. No image was silently relabeled. Local Habits do not require an external snapshot. The final acceptance record keeps package and native results separate from these historical illustrations.

Boundaries

  • Apple Silicon Mac only. No Intel, Universal, Windows or mobile release.
  • Local signature, no notarization and no automatic update system.
  • External Codex installation; account, model, quota and online-service availability are conditional. Not every ChatGPT account or arbitrary Codex version is guaranteed to work.
  • Dictation is online draft input. Explicit Cancel discards that input. It is not live voice conversation.
  • Automation checks only while the app process runs. Sleep, quit or failures may prevent it; no wake-up or precise-time delivery guarantee.
  • No new-user Dida onboarding or app-managed cloud sync. Verify local, external and cloud results independently.
  • Recovery material is not a complete backup. Conflicts are not automatically merged and arbitrary downgrades are not guaranteed format-compatible.
