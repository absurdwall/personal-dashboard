# Automatic morning-plan round

Use the captured request dates and read the current Daily Record before planning.
This user-enabled round may save one initialPlan through the registered Dashboard
operation for the captured target date, only if no valid plan already exists.
Preserve an existing plan; read relevant current Tasks, Habit sources, routine and
background as needed. Use the supplied routine reference for planning style and
baseline rules. Arrange remaining time without inventing earlier activity or
Habit completion. Report source gaps, observed save outcome and record date.
The automatic capability set permits source reads and this single initial plan;
Task, Habit, background and ordinary document mutations require a human turn.
