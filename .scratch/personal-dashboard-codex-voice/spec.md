## Problem Statement

用户在 Collaboration 中口述时需要手动选择中文或美式英语，Apple 离线识别还依赖本机已安装的语言资源。中文资源缺失会让录音入口不可用；这台 Mac 已补齐资源，但用户希望以正常的 Codex / ChatGPT 登录直接使用云端听写，免去语言与本地模型管理。

用户的实际口述包含中文、英文专名及整句英文，并经常超过一分钟。现有 60 秒自动停止与这种使用习惯不符。用户希望自然、连续地表达，检查转写，再手动发送；没有要求在 Dashboard 中实现双向语音对话。

## Solution

Collaboration dictation 使用 Codex WebRTC，复用现有 ChatGPT 登录。输入区保留麦克风开始/停止、取消及状态提示；不再要求选择识别语言，不增加引擎设置或离线备用选项。录音时展示用户转写预览，停止后将收尾文字追加到原会话、原目标日期的可编辑草稿，再由用户手动发送。

删除产品的 60 秒自动停止，不设置替代的固定录音时长自动停止。切换会话、日期或离开 Collaboration 时停止采集，并收尾保存到原目标。取消丢弃本次听写；断网或服务失败保留已收到的文字及既有草稿，明确标记未完成，由用户手动重试。

应用内 Apple 语音路径退役，macOS 共享语言资源保留。录音区域准确说明音频通过 Codex 在线处理。实时服务产生的助手回复与用户转写分开，助手回复不进入草稿，也不播放。

## User Stories

1. 作为 Dashboard 用户，我希望用正常的 Codex / ChatGPT 登录开始听写，以便不用开通 API 账户或准备 API key。
2. 作为 Dashboard 用户，我希望 Collaboration 默认使用 Codex WebRTC，以便不用选择识别引擎。
3. 作为 Dashboard 用户，我希望输入区不再提供离线语言和备用服务选择，以便入口保持简单。
4. 作为中文用户，我希望直接用普通话口述，以便不用先确认本机中文模型是否安装。
5. 作为英语用户，我希望直接用英语口述，以便不用改动语言设置。
6. 作为中英混合口述用户，我希望中文、英文专名及整句英文保留原语言，以便减少改字和重新输入。
7. 作为双语界面用户，我希望切换界面语言不改变听写语言，以便显示偏好与表达方式独立。
8. 作为用户，我希望点击输入区麦克风即可开始听写，以便操作集中在当前草稿附近。
9. 作为用户，我希望清楚看到权限请求、连接、录音和收尾状态，以便知道什么时候可以说话。
10. 作为用户，我希望录音中看到当前用户转写预览，以便确认输入正在被接收。
11. 作为用户，我希望手动停止录音，以便自主决定一次口述何时结束。
12. 作为长段口述用户，我希望超过 60 秒仍能继续录音，以便完整表达一段想法。
13. 作为用户，我希望停止后能识别最后一句话，以便末尾内容不会悄悄丢失。
14. 作为用户，我希望转写结果进入可编辑草稿，以便修正识别错误。
15. 作为用户，我希望停止录音不会自动发送，以便我先审阅再提交。
16. 作为用户，我希望转写追加到已有草稿，以便此前输入的文字保留。
17. 作为用户，我希望录音期间修改的草稿仍保留，以便转写不会覆盖我的编辑。
18. 作为用户，我希望最终文字不重复追加，以便增量、最终事件和重复回调不会产生重复句子。
19. 作为用户，我希望助手的实时回复不进入我的草稿，以便输入只代表我说的话。
20. 作为用户，我希望 Dashboard 不播放助手语音，以便本轮保持听写体验。
21. 作为用户，我希望口述内容不会触发正式协作回合或业务操作，以便只有手动发送后才开始工作。
22. 作为用户，我希望取消能丢弃本次听写，以便放弃不需要的输入。
23. 作为用户，我希望取消不影响已有草稿，以便此前写好的内容保留。
24. 作为用户，我希望取消后的迟到事件不再写入草稿，以便取消有明确效果。
25. 作为用户，我希望断网或服务失败时保留已识别文字，以便不用完全重新口述。
26. 作为用户，我希望不完整转写有清楚标记，以便不会把部分内容误认为完整结果。
27. 作为用户，我希望手动决定是否重试，以便失败不会自动重复上传、录音或切换引擎。
28. 作为用户，我希望未登录或登录失效时看到现有连接入口，以便恢复账户连接。
29. 作为用户，我希望权限拒绝、空结果或识别失败有具体状态，以便知道为何没有新增文字。
30. 作为用户，我希望草稿保存失败时文字仍可编辑，以便不会丢失尚未成功保存的结果。
31. 作为用户，我希望录音中切换会话时自动停止并保存到原会话，以便文字不串到新会话。
32. 作为用户，我希望录音中改变目标日期时文字仍归属原日期，以便内容不会静默改写目标。
33. 作为用户，我希望离开 Collaboration 时停止采集并收尾保存，以便没有后台持续录音。
34. 作为用户，我希望权限请求或建连中离开后不会开始录音，以便迟到回调不会重新采集声音。
35. 作为午夜后使用的用户，我希望跨过 04:00 边界不会改变已开始听写的归属，以便生活日切换不挪动输入。
36. 作为用户，我希望导航后收尾文字不会覆盖新页面的草稿，以便两个目标各自独立。
37. 作为用户，我希望停止、取消、失败及关闭应用时释放麦克风和连接，以便资源不会持续占用。
38. 作为用户，我希望知道音频通过 Codex 在线处理，以便理解语音输入的数据流向。
39. 作为用户，我希望应用不保存原始录音或在日志里写入转写正文，以便语音内容不会形成额外的本机数据副本。
40. 作为用户，我希望既有 Vault 和业务写入审核继续适用，以便听写不会绕过确认流程。
41. 作为用户，我希望实际安装候选验证过麦克风和云端识别，以便浏览器原型的成功能转化为日常可用功能。
42. 作为用户，我希望听写输入与未来语音对话区分清楚，以便本轮交付聚焦已讨论的体验。

## Implementation Decisions

- **服务与认证**：唯一服务为 Codex WebRTC，复用现有独立 Codex profile、App Server 管理和 ChatGPT 连接状态。没有 API key 获取、单独转写 API 或备用服务路径；已有连接设置承担账户恢复入口。
- **先行运行时验证**：首先在真实打包 Mac 应用的 WKWebView 验证麦克风、RTCPeerConnection、SDP 交换、用户转写和尾段收尾。若失败，记录具体技术缺口，不把调研用 Chromium、Python 或 localhost 原型作为产品方案，也不静默切换技术路线。
- **协议版本**：已验证 Codex CLI 0.160.0 的实验 WebRTC v3 路径；当前服务端拒绝 v1，text 输出模式与该版本的 WebRTC 组合不成立。接入核对实际运行版本的协议与字段；采用已验证的 audio 输出形式，仅消费用户转写，忽略助手输出。
- **临时实时线程**：听写线程与正式 Collaboration session 的工作线程隔离，使用空白上下文与最小权限，不提供 Vault 背景、Dashboard 写工具或外部应用工具。提示词不能替代权限保护。启动、结束及服务侧委派不得形成正式协作消息或业务执行。
- **模块职责**：沿用听写输入控制器、浏览器采集运行时、协作 App Server transport 与现有草稿保存服务，替换本地一次性录音转写契约为流式连接/事件契约。草稿合并与目标归属由现有上层行为边界统一负责，不散布到多个事件处理入口。
- **用户事件契约**：接入用户转写增量与最终事件。输入身份、事件所属段及 role 必须可核对；仅本次有效输入的 user 文本可进入预览。最终文本校正对应预览，不能把 final 再当作新增 delta 拼接；assistant 和过期事件被排除。
- **唯一目标与落稿**：开始时绑定不可变的听写输入身份、Collaboration session 和 target date。一次输入收尾后最多提交一份聚合草稿结果，重复回调不重复落稿；落稿以最新草稿为基础，保留同时发生的用户编辑。
- **录音交互**：麦克风覆盖开始/停止，提供取消、实时预览和收尾状态。删除产品 60 秒自动停止，不换成另一固定时长自动停止；真实服务错误显式处理，不宣称服务永远没有限制。
- **停止与取消**：停止先释放本机采集，再按实际协议收尾。取消丢弃本次预览和结果，抑制迟到事件；原草稿保留。只做可编辑听写，不自动发送、不播放助手语音。
- **失败与重试**：断线或服务失败保留已收到的文字，标记不完整，追加到原草稿，由用户手动重试。未收到文字则只显示失败。没有自动重传、重录、重新连接后继续采集或切换引擎；保存失败保留内存草稿并明确提示。
- **导航与生活日**：切换会话、目标日期或离开 Collaboration 时立即停止采集，允许导航继续，收尾落原目标。在权限请求/建连阶段离开则取消待启动输入，迟到成功回调不能开启录音。跨过 04:00 不重绑已开始的目标。
- **生命周期清理**：成功、失败、取消、导航及关闭应用都清理 microphone tracks、peer connection、事件订阅和临时线程。关闭应用时尽力保留已收到文字，不承诺恢复尚未到达的云端尾音。
- **存储与日志**：复用现有按会话/日期保存草稿的模型和写队列，不建立第二套草稿或业务存储，不把临时语音线程保存为正式 Collaboration session。不持久化原始音频或复制凭据；日志不写音频、转写正文、SDP、账户标识或 Vault 内容。
- **Apple 退役**：移除 Apple 专属识别 helper、能力命令、语言偏好使用、编译/打包资源以及旧单语言测试约束。macOS 共享资源不作卸载，界面语言切换保持原义。
- **文案与设置**：去掉语言选择、离线能力及缺模型文案，说明在线处理和草稿审阅。单一服务不新增引擎设置；可访问状态、开始/停止/取消按钮和现有账户连接入口保持可达。
- **依赖与旧设计**：本轮没有批准其他依赖、识别服务或容器。新方案替代旧语音规格的 Apple 单语言技术范围；现有生活日、selected-Vault、草稿归属和业务变更审核边界保留。

## Testing Decisions

- **测试边界已确认**：2026-10-03 用户确认采用现有听写控制器到原会话草稿的行为边界，覆盖停止、取消、断线、迟到事件和跨会话归属；真实打包 Mac 应用另验麦克风、WebRTC、中英混说及超过一分钟口述。
- **最高现有边界**：主要自动测试驱动听写控制器及草稿路由的公开行为，观察预览、落稿、错误、目标身份、手动发送隔离与资源释放。transport、采集和时钟作为边界外可控协作者，避免为每个底层对象新增测试入口。
- **好测试的标准**：断言用户可见结果、持久化结果和必要副作用，不镜像内部函数、计数器或执行顺序。取消后迟到事件、final 校正 delta、重复事件和并发草稿编辑应导致正确最终文字，不能只证明某个方法被调用。
- **测试先例**：现有听写行为测试已覆盖权限拒绝、失败保留原草稿、取消后的迟到回调、原会话/日期绑定、草稿身份以及与手动发送共享写队列，复用这些原则并替换 Apple 单语言专属期望。协作 workflow 集成测试已有 transport/store 协作者和隔离目录，可验证临时语音线程不创建正式消息或业务写入。现有表面结构检查只补充控件与文案回归，不承担云端功能验收。
- **数据隔离**：自动化使用合成音频/转写、测试 transport、隔离目录及合成 Vault，不读取或改动个人资料。真实候选测试才使用获授权的麦克风及当前登录；日志和交付证据不暴露凭据或个人语音正文。
- **合并与身份测试**：已有草稿、录音期间编辑、增量到 final 的修正、重复 final、过期输入、assistant 输出、会话/日期切换及 04:00 rollover 均覆盖正确最终文字和原目标；同一输入不重复落稿。
- **停止与失败测试**：停止后收尾、明确取消、权限请求/建连期间离开、断网后的部分文字、空结果、登录/服务错误、草稿保存失败均有行为测试。用户手动发送不得被听写触发；取消后不落本次输入，失败保留已收到内容。
- **资源与隔离测试**：终止路径释放采集与连接并卸载临时线程；语音线程没有正式工作背景、业务工具、助手播放或正式消息写入。检验事件与资源行为，不仅依赖提示词或源码字符串。
- **真实 Mac 连通验收**：在打包 WKWebView、现有 ChatGPT 登录且无 API key 的条件下完成麦克风输入、SDP 连接与完整用户转写；Chromium 握手或合成短样本不能替代。
- **真人质量与长段验收**：分别口述普通话、英语、中英混说、英文专名；记录实际误识别和等待时间，结果保持可编辑。至少两分钟连续口述验证不会一分钟停止，并检查开头、中间及最后一句。当前用户关注中英，不据此承诺所有语言的准确率。
- **实机尾段与故障验收**：停止时说完最后一句、录音中断网、切会话/日期、去 Today、取消及关闭应用，检查麦克风释放、文字保留、无串写、未完成提示与无后台录音；确认返回原目标后草稿内容，以及保存成功后的重启持久化。
- **退役及回归验收**：候选包不再包含 Apple 专属语音 helper/构建步骤，UI 无语言或服务选择、无仅本机转写承诺；其他 Collaboration 草稿、手动发送、正式 Codex 工作、业务审核及界面语言仍可正常使用。
- **证据界限**：本规格发布和现有合成调研不等于真实交付，不据此关闭旧语音票的真人验收缺口。实现须明确区分自动测试通过、连接验证、真实候选验收和用户体验认可。

## Out of Scope

- 双向语音对话、助手语音播放、实时语音驱动正式 Codex 工作或业务写入。
- Apple、Whisper、MLX、系统听写入口及任何离线备用或服务选择设置。
- API key 接入、单独计费的转写 API、新的身份/凭据管理或其他外部服务。
- 切换页面后继续后台录音，以及未确认的新固定录音时长自动停止。
- 系统共享语言资源卸载、个人 Vault/账户资料清理或重新组织。
- 移动平台语音交付、所有语言质量保证，以及订阅无限额度或无限服务时长承诺。
- 本次规格发布中的实施拆票、代码认领、产品实现、打包替换或业务数据变更。

## Further Notes

用户已确认服务、听写、失败保留、手动停止和离开即停止的共同理解。用户个人更习惯切换页面后继续录音，但接受本轮先保存到原目标并停止；该偏好作为后续方向，不是本轮未完成项。

隔离调研用当前 ChatGPT 登录完成约 9.2 秒合成中英音频的完整 user 转写，未使用 API key。Apple 普通话资源也已安装并通过合成中文测试，但这不改变本轮唯一服务选择。当前账号成功不等于其他账号、订阅和版本都保证可用，具体语音额度仍未确认。

本规格遵循根领域词汇中的 Collaboration dictation、Collaboration session、selected-Vault 与 target date，并遵循 [ADR-0004](../../docs/adr/0004-use-codex-for-collaboration-dictation.md)。它明确替代旧规格的 Apple 单语言范围，保留生活日与业务边界，不改写历史规格。
