## 用户已经明确的方向

- 本轮 Collaboration 使用 Codex WebRTC 云端语音输入。
- 复用用户正常的 Codex / ChatGPT 登录，不要求 API key 或单独的 API 账户。
- 无需先手动选择输入语言，优先支持用户实际的中英混合口述。
- 最新取舍为本轮只用 Codex WebRTC；不增加 Apple / Whisper 备用入口，不增加引擎或离线语言选择设置。
- 成功调研只说明当前账号及合成短样本可工作；正式接入和真人验收尚未完成。

## 现有术语与事实

- **Collaboration session** 沿用根 CONTEXT.md：持久化的用户-Codex 工作线程，拥有自己的消息、目标日期和草稿。
- 本轮的“语音输入”指用户口述形成文字输入；需要明确区分用户转写与实时接口产生的 Codex 回复。
- 当前语音只出现在 Collaboration composer；现有选择为中文/美式英语，偏好存在本机。设置里没有语音引擎选项。
- 当前识别结果进入可编辑草稿，未自动发送；已有会话及目标日期归属保护。当前录音有 60 秒自动停止限制，不能未经讨论把它当成新云端体验要求。
- 原规格 `.scratch/personal-dashboard-lived-day-usability/spec.md` 限定本地手动单语言输入、无在线服务。本轮用户方向明确改变该语音部分；生活日、会话归属和业务写入边界仍需沿用。新规格应明确替代范围，不能静默改写历史规格。
- Apple 中文资源此前按用户要求安装，属于 macOS 共享资源；应用的产品入口、应用实现代码和系统资源是不同删除范围。

## 设计树与当前 frontier

已定：Codex-only 云端输入

1. 移除离线能力的范围
   - 已确认：移除应用内 Apple 语音界面和实现，不保留离线备用选项。
   - 用户允许自行判断系统共享资源的去留；本轮保留 macOS 资源，不做系统清理。
2. 用户转写如何进入草稿
   - 已确认：只做听写输入；录音中显示用户转写预览；停止后追加到已有可编辑草稿，用户手动发送；不播放或显示助手回复作为输入。
   - 用户明确说明：语音对话体验需单独做大量交互及质量工作，不属于本轮。
3. 离线/断线/额度或登录失败
   - 已确认：取消丢弃本次输入；失败/断线保留已收到的用户文字及原草稿，明确标记未完成，由用户手动重试；不自动重录、重传或切换引擎。
4. 连续口述与停止
   - 已确认：删除旧实现 60 秒自动停止，产品不设固定录音时长的自动停止，支持用户手动停止的连续口述。
   - 用户日常口述经常超过一分钟；不能沿用旧限制或未经确认换成另一个产品固定时限。
   - 用户以 Codex Dictation 的体验作参照；这不构成对该服务实际无限时长的核实。本轮约定产品行为，不承诺服务永不发生限制或失败。
5. 录音中切换会话、目标日期或离开 Collaboration
   - 现有代码会取消录音；已进入转写阶段的结果保留原会话及日期归属。
   - 已确认：停止采集并收尾本次用户转写，保存到开始录音时的原会话/目标日期草稿；不继续后台录音，不把文字带到新会话。
   - 用户偏好记录：个人习惯更希望切换后继续录音，但明确接受本轮先采用上述停止行为。后台持续录音属于以后可重新评估的方向，不是本轮未完成项。

实现收尾时必须处理尾段，避免重复追加；失败文字随本次输入收尾保留到原草稿。尾段等待与服务协议的技术事实由实现验证，不要求用户猜测接口行为。

## 文案与验收约束候选

- 录音区域须如实说明音频通过 Codex 在线处理；不得沿用 Apple 入口的“只在本机转写”承诺。
- 本轮只覆盖 Collaboration；界面语言切换保持原义，不再决定识别语言。
- 麦克风权限、现有 ChatGPT 登录、当前账号语音服务可用性及网络是可用性前提；实验接口版本与未知订阅额度不能包装成全账号保证。
- 支持证据：`.scratch/personal-dashboard-usage-feedback/2026-10-03-voice-options-research.md`。
