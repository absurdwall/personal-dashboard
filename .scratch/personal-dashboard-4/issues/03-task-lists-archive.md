# 03: 清单分类、归档与恢复

**What to build:** 用户能分类任务、按清单新建，并归档或恢复整张清单而保留任务历史。

**Blocked by:** 01 Tasks 入口与持久化收集箱

**Status:** resolved

Type: task

- [x] 支持单层清单创建、改名及任务跨清单移动；按身份关联，不因清单改名丢任务。不引入嵌套文件夹或删除清单的隐式批量删除。
- [x] Inbox 是永久默认清单，可含有日期和无日期任务；普通清单中新建默认当前清单且无日期，全局／Inbox 默认 Inbox。
- [x] 归档清单退出活动集合与日常待办，提供归档查看及恢复入口；保留所有任务的现有状态和历史，不批量完成／放弃。不要求 02 的状态编辑 UI 才能实现。
- [x] 恢复清单按任务当前状态恢复正常可见性；恢复单条任务不自动取消清单归档。归档读视图可供后续 Calendar 复用。
- [x] 移动任务与清单归属、归档状态的写入使用 01 的原子边界；失败／并发不能产生悬空归属、丢失或重复任务。计数符合当前集合。
- [x] 合成数据验证创建／改名／移动／归档／重启／恢复，包含已有非待办状态、未完成归档及双 Vault 隔离；提供完整界面演示与双语固定文案。
