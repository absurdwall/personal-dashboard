## What to build

凌晨在 Today 记录 Daily Record 或本地习惯时，默认仍归前一个生活日；04:00 后新操作默认进入新生活日。用户可看到并显式选择归属日期，跨边界的已有编辑保留原目标。

## Acceptance criteria

- [ ] 复用并扩展现有时钟边界，将生活日判定与真实时间戳分离；Today 与本地习惯展示、写入校验采用同一规则。
- [ ] 03:59:59 归前一生活日，04:00:00 归新生活日；重新打开及休眠恢复重新判定默认日期。
- [ ] 手动选定日期、已开始的编辑和待确认写入保留目标，显示日期与最终持久化一致。
- [ ] 自然日期、真实时间戳、显式 Task 日期／时间和已存历史归属不被批量更改；外部习惯证据保持来源与原日期。
- [ ] 在已有服务测试覆盖月末、年末、夏令时边界；以隔离 Vault 的 packaged App 路径证明记录、刷新和重启后的归属。
- [ ] 此票只交付默认日期及记录闭环；跨午夜时间轴展示由 #30 交付，协作接入及语义由 #31 交付，不能提前宣称整份 spec 已完成。

必要的局部整理首先在本票中完成：让生活日成为独立判定，不将原有所有自然日期调用机械替换。保留当前调用的语义和兼容行为，不单列广泛重构票。

## Shared verification

每票独立完成必要自动化与相关 packaged Mac 验收，使用隔离 Vault；真实布局及识别质量不能由源码断言或模拟录音代替。保留既有数据、来源、权限和草稿；不新增依赖或服务。验证基线包含已完成前置及已合入兄弟票，并回归本次触及的相邻功能。本次发布只创建实施队列，不代表认领或开始实现。
