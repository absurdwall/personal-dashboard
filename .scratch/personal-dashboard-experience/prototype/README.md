# Personal Dashboard 定稿原型 R

2026-10-10：依据用户逐轮反馈收敛。**Tasks、Evening、Collaboration、紧凑 Calendar、早晨文字安排和拖动后的时间同步均已获用户确认。** 用户对时间冲突时上下覆盖或临时并排均可接受，将选择交给 Agent；最终选择临时并排。本次交付是定稿原型，正式产品实现仍待推进，Workflow Retro 不在原型范围。

## 运行

```sh
npm run prototype:experience
```

打开终端打印的 `/revised.html?page=today&variant=R`，按导航查看 Today、Tasks、Calendar、Collaboration。全部是合成数据和内存状态，没有真实 Vault、账户、模型调用、持久化或安装。

## 本轮问题与修订

1. **Today 同一条时间轴**：计划、事实、Task 共享刻度与事件区域，没有按来源固定拆成左右两条轴。仅在相互重叠时并排排布。早晨页恢复文字安排，只在白天页使用时间轴。重叠事件临时并排，其余占整行，不固定分成三种来源的列。lived day 的 04:00–06:00 和次日 00:00–04:00 保留边界说明。
2. **模糊时间也定位**：示例将早晨／中午／午后／晚间分别放在约 09:00／12:00／13:00／18:00。条纹与“模糊计划”明确标识近似位置；卡片高度只是阅读空间，不代表精确时长。拖动到其他位置后仍为“约 HH:MM”，不会自动变成精确范围。点击计划可在模糊与具体起止时间间切换。
3. **机械文档同步**：拖动、修改精度、调整结束时间，通过同一条计划 id 直接改变时间字段，同时更新“早间计划”和“当前安排”的 Markdown 预览。点击“查看对应文档”可检验文本，改动前初始快照与每次修改保留。没有调用 LLM，也没有新增审批步骤。示例 Markdown 仅用于展示对应关系，不是生产 Daily Record 格式契约或持久写入实现。
4. **Tasks 以原版 B 为基础**：保留清单侧栏，中心简洁勾选列表，点击任务在详情区查看内容／日期／时间／列表，不把长说明和多个操作铺在每行，也不做任务时间轴工作台。增强勾选框保留。
5. **Calendar 紧凑月历**：本月 35 个格子等高，按窗口高度约 90–106px，四行预览仍保留。“记／复”默认缩小放在日期右侧；右上角可切换为右下角，两种位置都不为标记单独留一行。更多项数放在日期行。

## 实现时需明确的文档模型

规格前问答补充：用户确认的核心是**显示与对应文档一致**。改变早间安排就更新早间部分；改变白天计划更新或确认记录就更新白天对应部分。原型按共享 id 同时修改两个段落，只是此前演示，不能作为正式产品无条件双写的要求。具体默认编辑归属见 [design-review](../design-review.md)。用户另已明确确认 Task 区块保存为计划执行时间段，旧 Task 无时长时保留时间点；这是待实现能力。

Q3 已确认：**白天时间轴的正常拖动默认更新当前安排，早间安排保持独立**；只有明确进行早间规划或纠正时才修改早间部分。正式实现以 [to-spec 规格](../spec.md) 的来源归属为准。Q4 已确认复用业务操作、真实持久化及打包 App 的测试边界。旧的非模板 Spec 草稿已删除，新规格按 to-spec 七章节重写，并按用户指示正式 [发布到本地 tracker](../map.md)；[发布记录](../publication.md) 单独保留。原型现有双写行为不代表该最终规则，原型没有真实文档写入。

此前 R 演示“用户显式修改同时更新两个计划段落，保留改动前版本”，没有落实真实写入。规格以本轮澄清后的对应来源一致性为准，并结合 [CONTEXT](../../../CONTEXT.md) 中 morning baseline 与 current arrangement 的独立身份，明确编辑归属与修订历史，保留修改前证据，再落实正式写入。原型的视觉结构已确认，不代表双写演示已成为正式持久化规则。

现有 Task 尚无持久时长字段；原型选区长度用于体验演示，正式规格将按已确认的计划执行时间段定义持久化契约。`/retro` 补全仍只是已有 skill 对话的可发现入口，不发送消息、不硬编码另一个执行模型。

## 时间冲突的最终选择

用户所说的“重叠”是卡片占同一空间、上下覆盖，并非并排。用户明确表示两种方式均可接受，没有固定偏好。Agent 选择临时并排：同一时段的计划、Task 与事实都能看见且容易选中，减少被遮住的点击与拖动目标；没有时间冲突时仍占整行，不按来源固定分成三列。沿用 R 现有实现，无需再次改动原型界面。

## 检查与保存

浏览器亲手验证：具体计划 08:00–10:00 → 10:00–12:00 后，两处 Markdown 都更新；模糊午后 → 约 14:00 后保持模糊精度；切成 18:00–19:00、拖动结束时间 → 19:30 后文本同步，事实不改变；B 列表点击任务展示详情与勾选完成；日历全部 35 格等高、四行预览、“记／复”状态保留。本轮另外核对早晨页只有文字、白天页仍是统一时间轴；在 1280×720 和 830×758 窗口里，整月网格底部均处于可见区域内，35 格等高，四行预览未超出日期格，两种标记位置可以切换。仅原型演示，不等于正式安装版验收。
