## 三套方案要回答的问题

| 页面 | A 一屏概览 | B 精细右栏 | C 按需聚焦 |
| --- | --- | --- | --- |
| Today | 大窗口一屏 06:00–24:00；就近任务浮窗是否够用？ | 精细日轴和右侧详情是否便于连续编辑？ | 全日概览和上午/下午/晚间聚焦切换，能否兼顾阅读与拖动？ |
| Tasks | 紧凑属性在 Content 上方，是否妨碍开始写内容？ | Content 优先，属性放下面；是否更顺？ | Content 优先，额外属性展开；是否容易找到优先级/标签/父任务？ |
| Collaboration | 背景在消息与输入之间独立限高滚动；是否占用太多聊天高度？ | 大窗口会话/聊天/背景侧栏，窄窗口背景浮层；是否值得常驻？ | 按需背景浮层，避开输入与听写控件；是否更自然？ |
| Calendar | 右侧同时阅读计划与复盘 | 右侧计划/复盘标签切换 | 右侧分节展开回顾；原月历结构不重新投票 |
| Habits | 统计在详情上方 | 统计在右侧，打卡区域靠前 | 紧凑统计列表，窄窗口重新排布；哪种信息层级更好？ |

所有方案固定使用同一 Tasks 清单＋右栏、等高月历＋右侧日期回顾、Habit 列表＋详情。允许逐页拼选，不要求整套胜出。

## 建议过目顺序与操作

1. **Today A → B → C**：同窗口比较同一日。点“精细放大/一屏概览”；点时间轴 Task，不跳到午夜详情；B 编辑右栏，A/C 用浮窗。拖动“下午”到 16:00 后看“约 16:00”，再点“对应文档”对照早间仍为“下午”。拖动 Task 区间保留时长；拖动具体计划或其底边；事实不能拖动。`04:00–次日04:00` 可展开完整 lived day 边界。窄/短窗口默认可滚动尺度。
2. **Tasks B → A → C**：点任务默认聚焦 Content，直接修改粗体标题；打开日期、清单、起止时间属性，已有结束时间时可清除结束。Save / Cancel 同行，窄窗口固定在面板底部。优先级排序、标签筛选；文件夹箭头收起/展开，点文件夹名按原清单分组；快速添加在创建前选日期和目标清单。父任务列直属子任务，子任务可再添加子任务，完成互不级联。More 和右键共用操作菜单；“取消时间安排”保留日期；“删除 Task”移除共享身份并保留其子任务。
3. **Collaboration A → B → C**：展开背景，滚动其内容，从自身标题“收起”；模拟听写 → 加片段 → 停止进入可编辑草稿 → 编辑 → 发送。空预览不占空间；转写在输入框下面，预览可收起。输入 `/` 后 ↑/↓ 选择、Tab/Enter 补全、Esc 退出。`/retro-week`、`/retro-day` 明确是模拟候选，仅 `/retro` 是原有入口；补全不发送，回复均为样例。
4. **Calendar**：先选 12 日，再点顶部 ＋，创建浮窗里日期可展开修改；创建不补造 Daily Record。点 Task 在月历上方浮窗编辑，关闭后背景位置保留；在 Tasks/Today 找到同一 id。右侧 Open full Today 打开所选日（合成日期示例）。关闭节日样例；比较三种回顾呈现。短窗口月历内部滚动，35 格始终等高并保留四条任务预览。
5. **Habits**：顶部 ＋ 新建，随后直接本地打卡。选择“活动身体”，编辑每周 3 天 → 5 天，详情显示当前目标和 10 月 12 日待生效目标；重复今天打卡仍只增加一个达标天。点 6 日撤回本地完成，外部证据仍支持这一天。选择“阅读”看有限覆盖及全历史未知；选择“按时起床”看阈值设置（达标不等于实际起床时间）。停用从日常列表收起，“查看停用”后可以恢复；历史、id、统计保留。
