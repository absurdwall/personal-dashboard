# 本轮原型浏览器体验检查 · 2026-10-11

范围：`refinement-prototype.html`，全合成数据、内存状态。Codex in-app browser 直接点击、输入、拖动、截图和检查渲染后的布局；没有编写原型测试，没有运行产品 build、Rust 检查、打包或安装。

## 已体验的行为

- Tasks 编辑 Content 后 Save，重新渲染读回修改；打开任务聚焦 Content。窄窗口 Save/Cancel 固定可见。右键/More 用同一菜单，包括浮窗里的 More，菜单能实际接收点击。
- 取消 Task 时间后仍保留 2026-10-10 日期，Calendar 中仍有同一 Task。Calendar 选择 12 日，顶部 ＋ 创建浮窗预填 12 日；创建后显示在该格及右侧，右侧仍明确没有 Daily Record。点击编辑浮窗、关闭后月历背景保留。
- Today 从“下午”（默认 anchor 13:00）手动拖到 16:00，当前安排显示“约 16:00”；文档面板读回早间基准仍为“下午”，事实不变。状态面板可查看完整共享 Task 和计划身份。卡片使用 R 的临时重叠分列，设置最小点击高度。
- Habit 每周三天改五天，显示本周按三天、10 月 12 日生效五天；今天打卡与同日重复打卡后，本周保持 3/3 天，累计不重复增加。最高连续包含已经达标的当前周，避免出现当前连续大于最高连续。
- Habit 停用后从日常列表消失，“查看停用”能找到它，恢复后历史、待生效目标保留。“阅读”显示有限覆盖及全历史未知。新建“喝水”后直接打卡，读回本月/累计/当前/最高均为 1 天。
- Collaboration 模拟转写出现在输入下方，加片段后停止，文字进入可编辑草稿，尚未自动发送。`/` → ArrowDown → Tab 插入 `/retro-week `，保持未发送，并明确标识模拟候选。只有确切 `/retro` 入口展示示例 retro；模拟候选是普通消息文本。
- 三套方案可通过浮动条切换，同一路由 `?variant=` 保持可分享。箭头键不抢输入框、select 或 dialog 内的编辑操作。

## 窗口检查

逐页打开 A/B/C × Today/Tasks/Collaboration/Calendar/Habits，检查 1280×800 与 680×560。截图保存为 `refinement-checks/<variant>-<page>-<width>x<height>.jpg`，共 30 张；另有 C 的 context＋voice 窄窗口截图。

- 宽窗口 A 的全日时间轴可见 06:00–24:00；需要操作短区间时可精细放大。B 的默认精细轴可滚动并在右栏编辑，C 增加时段聚焦。窄窗口默认采用可滚动尺度，避免把一天压成密集不可读刻度。
- 所有页面没有水平溢出。导航在窄窗口为紧凑横栏。Tasks 右栏在窄窗口覆盖部分列表，可以直接关闭；Content 与 Save/Cancel 保持可用。
- Calendar 保持 35 格等高；宽窗口整月可见，短窗口月历内部滚动，右侧日期回顾独立滚动。没有新增周视图或日期格双击/右键创建。
- 背景有自己的限高与滚动，空语音预览不占空间。A 的底部背景在转写展开时会压缩消息高度；B/C 的窄窗口浮层高度限定在输入区域上方。输入、发送/停止按钮没有被背景浮层覆盖。长转写预览内部可滚动。
- Habits 详情统计与打卡区独立滚动；B 的右侧统计在窄窗口移到上方，C 的紧凑统计重新排布。

## 检查中已修正

- R/F 的窄窗口样式覆盖把导航撑成长列，挤压工作区：本轮入口加了明确的响应式外壳覆盖，旧 R 不改。
- 卡片文字受旧 flex gap 和 shrink 挤压：移除多余 gap，并保留字行高度。
- 浮窗 More 菜单在 dialog 外部导致可见却不能接收点击：菜单挂到对应 dialog 并使用原生 popover 顶层。
- 侧栏/浮层 context 会遮住窄窗口语音入口：浮层高度根据实际输入区上沿收缩。
- C 聚焦切换误保留旧时段滚动像素导致空白：切换时段回到该时段开头。
