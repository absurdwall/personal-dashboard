## 修订依据与原则

用户认为17张票太碎，要求把同一处比较简单的小改动合并。提案现收敛为8张：
Tasks两张、Today一张、Calendar一张、Collaboration一张、Habits两张，加最终
整合验收。前版17张仅是草案，没有发布或分配实际 Work Item，因此可以重排
拟议编号；旧版草案仍保留在 Git 历史 `e4d1b30` / `3943d22`，不 amend。

名称/Content/属性/优先级/标签/普通菜单合成一个 Task 编辑切片；父子任务和
文件夹合成一个结构整理切片。节日跟 Calendar、slash 跟 Collaboration、
Habit停用恢复跟历史详情一起做，不为这些小项分别开票。

每张功能票仍是一条从实际操作、持久保存/读回到界面及验证的完整路径，不能
只交 schema/API/UI 中的一层。必要小型抽取在票内完成，没有独立的广泛重构
前置票。每票可分几次有意义的 commit，但只有该票完整行为验证后才关闭。

通用验收：稳定身份、旧数据兼容、revision/失败/重试、真实读回与重开、未
要求区域保留。实现前固定实际 App 基线；不因网页 prototype 改全局导航、
配色、字体、设置或未讨论的主体。正常 App 安装、main 合并和父 spec 关闭仍
是独立边界。

## 提议的完整切片

### PDEX-19：Task 编辑、属性与操作入口

**Blocked by:** None (can start immediately).

**What it delivers:** 保留紧凑列表和右栏，完成单一可编辑标题、默认 Content
聚焦、更大内容区、紧凑清单/日期/起止时间及同行 Save/Cancel；单行快速添加
可先选日期和清单。一起加入优先级、标签及排序/组合筛选，统一普通右键/More
动作，“取消时间安排”清 time/end 而保留日期，与删除明确不同。

**验收重点：** 创建、编辑、排序/筛选和菜单都作用于同一真实 Task，保存及
重开一致；旧 Task 缺省字段正确，其他入口更新不清新属性；标签改名/解除不
删任务，优先级不改变默认排序。草稿冲突和取消规则保留，无自动保存；无结束
时间时不常驻清除按钮。新建/详情共用能由右栏或浮窗承载的编辑行为，供后续
Today/Calendar使用。父子关系及其菜单由下一票增加，不在本票伪造占位功能。

### PDEX-20：Task 父子关系与清单文件夹

**Blocked by:** PDEX-19 — 扩展其已可用的编辑、快速添加及统一菜单，保留新属性。

**What it delivers:** 一起补齐任务结构整理：普通 Task 可关联/解除/换父任务、
添加及继续嵌套子任务，父详情显示直属子任务；清单可归入一层文件夹，箭头
展开收起，名称打开按原清单分组的汇总，添加目标明确可选。

**验收重点：** 父子各自日期、清单和完成状态，不级联完成；循环/自引用/无效
绑定拒绝，父删除不删子，恢复不覆盖新关联。文件夹删除只解组，清单与任务
身份保留；Inbox/All/Today固定入口保持，归档清单不重新进入日常待办。跨页
投影及保存重开正确；新增父子菜单复用原统一入口，不清优先级/标签或排期。

### PDEX-21：Today 时间轴与安排交互

**Blocked by:** PDEX-19 — 复用紧凑 Task 编辑行为及明确的排期/删除动作。

**What it delivers:** 将本页的改善一起完成：大窗口紧凑日间概览，按需精细放大
及完整 lived-day 入口；点击 Task 就近浮窗编辑且背景不跳；卡片边界完整、
长字省略、重叠可选。精确及可靠绑定的宽泛安排都可拖动，未操作的“下午”
保留措辞，拖到16点后保存为“约16:00”；当前安排编辑/取消保留早间基准。

**验收重点：** 1280×800/720、830×758、680×560的阅读/点击/拖动；精确区间
移动保留时长，默认anchor没有保存副作用，取消/冲突读回真实结果。保持
Morning/Evening、事实、普通当日任务、空白拖选与已有滚动/取消能力；只去掉
承担选中 Task 入口的底部重复详情，不搬迁所有底部内容，不产生假完成或事实。

### PDEX-22：Calendar 新增、详情与节日

**Blocked by:** PDEX-19 — 复用紧凑创建/详情编辑行为。

**What it delivers:** 在原月历结构内完成顶部加号创建（带入所选日期且可改）、
Task详情浮窗（关闭/保存背景不跳），同时加入中美节日轻量标注及可关闭设置。

**验收重点：** 点击日期仍看右侧计划/复盘并可打开完整Today；下方当日任务、
等高月历、标记位置和预览密度保留。创建不补造Daily Record，各视图同一Task；
仅替代大新建表单，不增加周视图或格子双击创建。节日本地数据/规则带核验
来源与年份覆盖，至少当年和下一年；没有覆盖不编造，不挤任务、不加服务/依赖。

### PDEX-23：Collaboration 空间与输入体验

**Blocked by:** None (can start immediately).

**What it delivers:** 把本页的小改动一起完成：保留A/C的聊天空间，使用限高、
独立滚动、就地收起的背景浮层；输入、发送和语音停止始终可操作，转写先在
输入下方预览、停止后进入草稿再由用户发送。Slash仅补多候选上下键选择。

**验收重点：** 背景＋转写在1280×720及窄窗口不裁掉停止按钮，长消息/背景/
草稿合理滚动；使用真实dictation和草稿服务，不复制模拟按钮。保留Enter/Tab
补全、Esc、IME、现有高亮/字体及真实模型/effort、会话、排队和能力边界。
多候选用合法测试供给验证，不向生产加入虚构命令，不加另一层审批。

### PDEX-24：Habit 新增、编辑与目标设置

**Blocked by:** None (can start immediately).

**What it delivers:** 新增和编辑一起做：顶部加号创建本地Habit，设置名称、
daily/weekly目标、开始日期及可选emoji/分组，直接在原今日列表打卡；编辑
共用表单并保留身份。目标有当前/待生效revision，周目标下周、日目标次日生效。

**验收重点：** 新增/编辑入口可发现，保存、实际跨日/周和重开正确；旧sourced
Habit及时间阈值兼容，外部snapshot刷新不覆盖本地设置/目标。重复打卡与双
来源每天只算一天，撤回本地不抹外部，创建重试不重复。历史用当时目标，待
生效可再改/取消，频率切换/开始日期不删除历史。保留原汇总与今日列表，无
TickTick创建要求，不把derived snapshot当可写主数据库。

### PDEX-25：Habit 详情、历史统计与停用恢复

**Blocked by:** PDEX-24 — 使用真实本地定义、完成及目标周期历史。

**What it delivers:** 左侧选中Habit才在右侧显示详情，可返回原今日列表；展示
本月/累计达标天、当前/最高连续、记录及编辑入口。详情可停用，从日常区收起，
仍能查看历史并恢复同一Habit；生命周期与连续统计一起完成。

**验收重点：** 历史读取不受12周快照限制造成假累计/最高；daily按天、weekly
按达标周，未知/有限覆盖/已知下界分别表达，不跨未知缺口连续。停用不删记录、
不填失败，恢复不生成新身份，连续不穿过停用期，历史最高和待生效目标保留。
跨周期、刷新、历史纠正及重开读回正确，默认不变成单项统计工作台。

### PDEX-26：整合与真实 App 验收

**Blocked by:** PDEX-20、21、22、23、25。

这些最终功能节点已间接包含19、24，不重复声明传递依赖。

**What it delivers:** 整合本轮功能为源码绑定的实际App候选，验证保存/重开、
拖动、跨视图、新旧数据及宽窄窗口，提供可审阅的结果与限制；对照原App基线
检查未要求区域未被顺带改动。

**验收重点：** 父子/文件夹/标签/优先级/菜单组合、Today/Calendar共同Task、
Habit目标/历史/停用/来源刷新、context＋voice＋slash以及失败恢复。每票已有
自己的测试，本票检查组合及真实Tauri保存路径；不以原型或纯mock代替真实
读回。保留base/branch/完整commits、构建来源、检查/界面证据及未覆盖项。
私有synthetic profile/Vault；正常安装、main合并与父spec关闭不自动执行。
