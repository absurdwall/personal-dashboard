# 02: 通过 Calendar 回看某一天

**What to build:** 从左侧 Calendar 选择日期，预览摘要，再阅读该日期的三个阶段，能随时回到今天。

**Blocked by:** 01 — 保留早间基准，展示当前安排

**Status:** ready-for-agent

- [ ] 采用冻结 FINAL 侧栏、月历、年／月选择、摘要与完整日期入口，不复用探索变体。
- [ ] 按明确日期读取及刷新，tab 切换保留日期，Today 恢复当前本地日；跨午夜不会悄悄改写所选日期。
- [ ] 有复盘默认晚间，无复盘默认日间；无记录和读取错误分开显示，浏览不创建文件。
- [ ] 真实日历日期验证与 vault 边界生效；单日异常不阻断其他日期，历史内容不随当前时间转成完成事实。
- [ ] 隔离工作流及 packaged Calendar-to-Today 导航、空状态、窄窗口与键盘操作验证通过。
