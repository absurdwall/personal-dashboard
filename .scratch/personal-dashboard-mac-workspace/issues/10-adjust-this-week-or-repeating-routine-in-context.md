# 10 — Adjust this week or the repeating routine in context

**Type:** task

**What to build:** Keep a one-week schedule adjustment close to its selected departure while placing future repeating-routine changes in the focused Routine settings subsection.

**Blocked by:** 05 — Replace the scrolling document with Mac workspace navigation.

**Status:** ready-for-agent

- [ ] An eligible upcoming departure can be adjusted from its This Week context using only established day and time presets.
- [ ] A one-week adjustment updates the current agenda and reminder state without rewriting the repeating routine.
- [ ] Settings exposes Routine as a visibly selected subsection and shows only its relevant controls.
- [ ] Repeating primary departures can be changed with established presets and affect future weeks without rewriting the current week.
- [ ] The interface clearly distinguishes a current-week exception from a repeating-routine change before confirmation.
- [ ] Ineligible, past, inactive, or otherwise unavailable changes are represented truthfully and cannot be submitted.
- [ ] Successful changes immediately refresh the relevant visible schedule and reminder-readiness state.
 - [ ] Packaged acceptance verifies both adjustment paths and their distinct persisted outcomes through real IPC.
