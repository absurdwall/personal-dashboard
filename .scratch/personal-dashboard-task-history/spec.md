# Task 完成后的默认收纳

来源：2026-10-03 用户反馈与 TickTick 原生只读观察。用户要求修理已完成项目持续堆在 Tasks 的体验。

- Tasks 全部／收集箱／自建清单／已归档默认主区只显示待办；已完成和已放弃放到默认关闭的历史区。
- 完成保存成功后移出主区；历史保留任务身份、原日期、真实完成证据、修改记录和重开／恢复入口。
- 侧栏只统计待办；显式已完成／已放弃筛选按完成日期／最后一次放弃日期倒序分组。缺失日期明确显示未知，不能借用安排日期。
- 历史首次展开或显式筛选最多创建 30 个任务编辑器，每次查看更多增加 30。直接打开保存任务须能定位更早的历史对象。
- Today 右栏将所选日期的完成项折叠；旧完成项不进入之后的 Today，逾期待办保留。Calendar 与时间轴仍保留日期内的事实证据。
- 固定文案双语。保存服务、正本格式、真实个人数据、Dida365 与语音输入均不修改。

验收：真实渲染 seam 复现再修复；完成／放弃／重开／筛选／分页／直接定位／跨日；完整前端与 TypeScript 检查；隔离 Vault 的原生 Mac 界面。

日用交付须有程序包指纹、真实 Vault 只读显示及数据保留证据；不能将代码、合成验收或 PR 单独当作安装已交付。
