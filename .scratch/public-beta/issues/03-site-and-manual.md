## Parent

Part of #116 — PDBETA-SPEC-01：Personal Dashboard 首次受邀 Beta 发布。

## What to build

参考 Bridge 的介绍与下载流程，为 Personal Dashboard 准备可本地预览的双语网页、面向用户的 README 和完整手册。用户能理解产品、核对条件、安装 DMG、创建自己的资料并使用已验证的现有功能。网页、README、安装指南、完整手册、限制和发行说明相互链接。

本票基于已验证的首次使用行为和明确的 Beta DMG 候选；文案草稿可以提前准备，最终内容须与包一致。不改 Bridge 项目，不把其他产品的能力或历史验收复制成本产品事实。

## Acceptance criteria

- [ ] 网页提供中英切换，包含用途、当前功能、合成数据真实截图、Mac 芯片/系统与 AI 条件、明确版本下载位置、安装与首用、手册、已知限制和反馈；桌面与窄屏可读。
- [ ] README 提供用户快速开始，并与网页和完整手册互链；开发构建说明与用户安装说明分清，历史记录保持为历史，不大范围重写。
- [ ] 手册完整覆盖个人空间、Tasks、Today、Calendar、Habits、Collaboration、语音、自动早间安排、04:00 lived day、资料位置、同步边界、备份/恢复、升级、卸载保留与脱敏反馈；说明与可实际执行的步骤一致。
- [ ] 用户自行安装兼容 Codex、设置中登录自己的 ChatGPT 的步骤准确且可复现，说明 Dashboard 独立登录资料和实际支持条件。无 AI 依赖时本地功能仍可用；不要求滴答，不承诺任意账号/客户端版本可用。
- [ ] 语音说明在线处理、可编辑草稿和手动发送；自动安排说明默认关闭、主动启用、App 必须运行及退出/休眠/失败边界；不宣传后台必达或自动同步。
- [ ] 发行身份为 1.0.0 Beta 1，明确本地签名/未公证；安装步骤包含复制至 Applications、推出 DMG 和首次系统放行，并区分受管设备或损坏提示的处理。
- [ ] 只使用合成截图/样例，不公开个人记录、账号、私人路径和凭证；已知限制按实际证据陈述，不把未执行或历史测试写成当前通过。
- [ ] 下载设计使用明确 tag 和资产，不依赖跳过 prerelease 的 latest 链接，不把 DMG 提交进网站源码；预览不包含虚假下载或指向错误候选的链接。
- [ ] 交付完整的可评审预览、文档和候选对应关系；检查互链、两种语言和实际使用路径。本票不启用 Pages、不发布可下载 Release；后续发布需最终候选和内容的具体授权。

## Scope and handoff

网页和文档改动走 PR，复用现有仓库与静态页面方式，不新增服务、依赖或大范围产品视觉改造。本票的完成是发布内容可审阅，不代表页面已上线或首次 Beta 已发布。
