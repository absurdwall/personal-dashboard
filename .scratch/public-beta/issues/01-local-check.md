## Parent

Part of #116 — PDBETA-SPEC-01：Personal Dashboard 首次受邀 Beta 发布。

## What to build

在现有功能上完成首次使用的 local check，并补齐发布必需的缺口：新用户创建自己的空白个人空间，使用本地 Task、Habit 和 Daily Record；需要 AI 时，按说明自行安装兼容 Codex，在 Dashboard 设置中登录自己的 ChatGPT，使用 Collaboration、语音转写和自动早间安排。留下可供后续打包和用户教学引用的实际结果。

这是用户确认合并后的单票，覆盖原六票草案中的前三项。以复用、检查和必要的小范围修复为主，不开展新的 AI 架构、功能平台或界面重设计。不因发现现有检查已经通过而重做功能，也不将检查结果等同于最终 DMG 陌生用户验收。

## Acceptance criteria

- [ ] 用户只需选择位置、命名文件夹，App 自动准备最小必要结构；也能选择已有兼容 Vault。不要求 Obsidian，不预装演示任务、日记、维护者背景、技能或凭证。
- [ ] 取消、不兼容非空目录、只读及创建失败给出明确结果；不静默转换或覆盖已有资料。正常使用采用中性产品术语。
- [ ] 创建和编辑 Task，确认 Tasks、Today、Calendar 展示同一对象；创建 Habit 并完成/撤销，保存首条最小 Daily Record；退出重开后独立读回。浏览日期不制造记录。
- [ ] 无 Codex、未登录、断网或未配置滴答时，本地功能继续可用；不建设新用户滴答接入，不删除维护者已有可选集成。
- [ ] 明确核实并记录普通用户可获得的外部 Codex 安装来源、版本及条件，形成可纳入网页/README 的最小复现步骤。安装包不内附、下载或代装 Codex，不新增安装向导。
- [ ] Finder 启动能发现说明中的 Codex；可靠处理旧版或不可用候选。设置中登录用户自己的 ChatGPT，执行一项合成数据的真实 AI 修改，并从业务页面/文件独立读回；不依赖维护者登录或私人环境。缺少长期背景和外部日常技能不阻止基础 Task 操作。
- [ ] 未安装、不兼容、登录取消、权限/额度不足及网络失败有可恢复提示，保留草稿和已确认结果。保留现有机械持久化边界，不加第二套语义授权拦截。
- [ ] 真实麦克风检查中文、英文及混合输入，文本落为可编辑草稿并由用户主动发送；检查停止/取消、导航和退出边界。模拟测试不替代真实识别质量结果。
- [ ] 自动早间安排默认关闭，新空间可主动启用而不要求维护者旧日程的虚假交接；App 运行期间生成、保存并读回计划，重复检查不重复生成，失败状态真实。彻底退出后不执行，不新增常驻后台、开机启动或自动唤醒；已有调度的防重复边界保留。
- [ ] 复用现有业务、前端和 packaged acceptance 接口，运行与实际变更相称的检查；证据绑定源码、候选包、运行时和合成数据。区分通过、失败、未执行、仅协议声明通过与真实模型/语音通过；发现的非本轮问题单独记录，不无界扩展本票。

## Scope and handoff

实施走受保护主分支的 PR。使用隔离的合成资料和不索引的临时候选，不改维护者个人 Vault、账号或正式安装。向后续票交付可复现的首用步骤、外部 Codex 条件、必要修复、已知限制及准确验收记录；本票不产出公开下载入口，也不认定发布完成。
